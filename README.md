# CYRUS YSR — Real-Time Interactive Portfolio

An Award-Site grade, GPU-accelerated real-time WebGL portfolio engineered with **Three.js**, **GLSL Shaders**, **EffectComposer Post-Processing**, **GSAP**, **Lenis**, and **Web Audio API**.

Built with a pitch-black obsidian (`#000000`) and molten Lava Orange (`#FF4D00`) aesthetic — zero build step required, deployable directly to **Vercel** or **GitHub Pages**.

## Interactive Chapters

1. **CH.01 — Void & David**: Opens in pure darkness with 28,000 floating particles that organically coalesce into a breathing, mouse-reactive 3D Michelangelo's David point-cloud sculpture before decoding the typography.
2. **CH.02 — Magma Singularity**: The Lava Orange `*` next to `YSR` seamlessly expands directly in-place to engulf the entire screen while surrounding content scatters outward, transitioning into domain-warped molten lava fluid.
3. **CH.03 — Thermal Lava Ink**: Liquid-magnifier zoom reveal paired with a Ping-Pong FBO advection shader allowing you to paint glowing 100% Lava Orange thermal ink trails across the canvas.
4. **CH.04 — Selected Systems**: Full-scene architectural artworks (`MICRO-COMMERCE`, `REALTIME IM`, `CLOUD DISK`, `PVZ ENGINE`) revealed via a liquid rubber membrane distortion shader with glowing molten seams.
5. **CH.05 — From The Lab → Tech Stack**: 28,000 particles assemble into a breathing 3D Anime Girl sculpture, then shatter and stream rightward as a floating glassmorphic Tech Stack panel glides in with mechanical rolling digit counters.
6. **CH.06 — Analog Vinyl Sanctuary**: Physical turntable with spinning grooved vinyl, animated tonearm, bass-driven vibration, and a hover fan-out stack of 5 classic piano pieces synthesized live via Web Audio API (*Croatian Rhapsody*, *Canon in D*, *The Truth You Leave*, *Castle in the Sky*, *Night Piano No.5*).
7. **CH.07 — Particle Signature Finale**: Aceternity-style cursor-scrubbed text reveal quote above a full-width 28,000-particle `CYRUS YSR` interactive wordmark, accompanied by a right-edge Sound Wave Navigator.
